Proceso de depuración en DevTools

  1. Reproduce el error en la aplicación.
  2. Abre DevTools y consulta la consola.
  3. Coloca un punto de interrupción en el código.
  4. Inspecciona las variables y el flujo de ejecución.
  5. Corrige el problema y vuelve a probar.

Conceptos de cliente

DOM
Modelo de objetos que representa el documento HTML como un árbol que JavaScript puede consultar y modificar.
ECMAScript
Estándar que define el lenguaje JavaScript y sus características.
Event Loop
Mecanismo que coordina la ejecución del código, la pila de llamadas y las tareas asíncronas del navegador.
